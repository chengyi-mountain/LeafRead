# LeafRead · 一片叶子的阅读器

> 一个**零依赖、纯离线**的网页阅读器：下载 `reader.html`，双击就能读书。
> 不用装软件、不用起服务器、不上传任何数据 —— 书和笔记都留在你自己的电脑/手机里。

**在线体验**：[chengyi-mountain.github.io/LeafRead](https://chengyi-mountain.github.io/LeafRead/)
**直链**：[reader.html](https://chengyi-mountain.github.io/LeafRead/reader.html)

> 分享链接请用 `https://` 开头：微信打开 `http://` 链接会先弹「该页面采用未加密的 HTTP 协议」拦截页，点“继续访问”可进入，但用 https 链接不会有这一层。

## ✨ 为什么是 LeafRead

- 🍃 **极小主文件** — 主程序 `reader.html` 约 **250 KB**，两本长篇内置书放在 `books/` 目录里**点开才下载**，首屏不再等 1.5 MB
- 📴 **完全离线可用** — 运行期不请求任何外部服务；内置书一旦加载过就留在本机，断网、飞机上都能读
- 🗂️ **进度和笔记在自己手里** — 只写浏览器 localStorage，可一键导出/恢复备份，不经过任何服务器
- 📱 **手机、平板、电脑同一套界面** — 自适应布局，手机上左右点击翻页、中间点击唤出顶栏

## 📖 阅读功能

| 功能 | 说明 |
|---|---|
| 双阅读模式 | **滚动**（连续流）与 **翻页**（多列排版、整页翻动、翻书阴影）随时切换 |
| 六套主题 | 日间、夜间、护眼绿、森林、海洋、**水墨屏**，可跟随系统深色模式 |
| 字体与字号 | 衬线 / 无衬线 / 等宽三套字体，字号、行距、页宽可调 |
| TTS 朗读 | Web Speech API，播放 / 暂停 / 上句 / 下句 |
| 划词查询 | 选中文字即弹出词典与翻译 |
| 全文搜索 | 命中高亮，点击结果直接跳章定位 |
| 书签与笔记 | 选中文字加笔记，书签快速跳转，全部本地保存 |
| 阅读统计 | 累计时长、连续阅读日历 |
| 快捷键 | `←` `→` / `PageUp` `PageDown` 翻页，`Esc` 关闭面板 |

## 📥 导入自己的书（本地文件，不经服务器）

书架页顶部有两个按钮：

| 按钮 | 用途 |
|---|---|
| **导入本地文件** | 唤起手机/电脑的文件选择器，可**多选**。TXT、EPUB、Word、PPT、Excel、Markdown、HTML、FB2、CBZ 等都能直接选，解析全在本机完成，文件不会上传到任何服务器 |
| **粘贴正文** | 没有文件、只有一段文字时用；首行可写成书名，正文里像「第X章」「Chapter N」的行会自动分章 |

「拓展书库」里点某本外部书目时，也会弹同样的三选一：**从手机选文件 / 粘贴正文 / 从网址导入**。

> 关于「从网址导入」：静态网页没有后端，浏览器同源策略（CORS）会挡掉大多数第三方站点的正文抓取，所以它会经常失败。**本地文件导入是更可靠的方式**。

## 🔍 搜索范围（重要）

书架搜索框只搜**你本机书库里的书**（内置 4 本 + 你自己导入的），不会去全网检索——原因是本页面没有服务器，浏览器也不允许它直接抓取别人的网站。

当本机搜不到时，页面会在空状态下方直接给出四个公开入口，点一下就带着关键词跳过去：
古腾堡公版书库、豆瓣读书、微信读书、必应。

## 📥 导入格式

| 格式 | 状态 | 说明 |
|---|---|---|
| TXT / Markdown | ✅ | 自动按空行与“第 X 章”标题切分章节 |
| HTML / HTM | ✅ | 自动剥离标签、提取正文 |
| EPUB | ✅ | 内置原生 ZIP 解压 + 读取 OPF 的 spine 顺序，按真实章节结构导入 |
| DOCX | ✅ | 读取 `word/document.xml` 正文段落 |
| PPTX / XLSX / ODT / ODP / ODS | ✅ | 分别按幻灯片、工作表、ODF 正文提取文本 |
| CBZ | ✅ | 漫画压缩包，逐页图片浏览 |
| PDF | ❌ 暂不支持 | 不含 PDF 渲染库，请先转成 TXT / EPUB 再导入 |
| CBR（RAR 漫画） | ❌ | 请转换为 CBZ |
| MOBI / AZW3 | ⚠️ 部分 | 二进制格式，只能尽力提取可读文本 |
| 网址抓取 | ✅ | 粘贴文章 URL，自动提取正文（需要联网） |

> 解压 EPUB / DOCX / CBZ 用的是浏览器原生 `DecompressionStream`，**没有任何第三方 JS 库**，所以这个单文件永远不会因为 CDN 挂掉而失效（需要 Chrome / Edge / Safari 16.4+ 等现代浏览器）。

## 🚀 开始使用

**方式一：在线体验**（推荐先点开看看）
打开 <https://chengyi-mountain.github.io/LeafRead/reader.html>

**方式二：本地使用**
1. 下载 `reader.html`（想读《德古拉》《白鲸记》的话，把 `books/` 目录一起下载下来，和它放在同一层）
2. 双击，用 Chrome / Edge / Safari 打开
3. 直接开始读内置的四本公版书，或拖入自己的文件

> 只拷走 `reader.html` 也能正常打开、阅读导入的书；只是点开那两本长篇时会提示「正文未随页面提供」。

| 书名 | 作者 | 章节 | 体量 | 加载方式 |

| 爱丽丝漫游奇境 | Lewis Carroll | 2 章 | ~49K | 随主文件 |
| 爱丽丝镜中奇遇 | Lewis Carroll | 1 章 | ~13K | 随主文件 |

> 为什么拆开：整包 1.6 MB 内联在页面里时，国内访问 GitHub Pages 的实测速度只有 20–30 KB/s，首屏要等 **50 秒以上**；拆开后主文件只剩 250 KB（gzip 更小），首屏 3–6 秒，长篇点开时再单独下载并缓存。

## 🧱 技术构成

- 纯 HTML / CSS / JavaScript（ES6+），零第三方库、零构建步骤
- 分页用 CSS 多列（`column-width` + `scrollWidth` 计算页数），`transform` 整页平移
- 数据持久化：localStorage（`reader_state_v2`、`reader_settings_v2`、`reader_bookmarks_v2`、`reader_highlights_v2`、`reader_notes_v2`、`reader_stats_v2` …）
- 文件解析：`DecompressionStream` 原生解压 + 正则提取 XML/HTML 文本
- 无障碍与移动端：触摸手势、点击热区、安全区适配

## 🐞 已知限制

- PDF、CBR、加密 MOBI 无法直接阅读（见上方格式表）
- 内置英文公版书正文在个别位置存在**单词间空格丢失**（原始文本换行拼接遗留），属内容数据问题而非解析缺陷
- 《德古拉》《白鲸记》存放在 `books/` 目录，本地只拷 `reader.html` 时无法打开这两本
- 搜索只覆盖本机书库，不做全网检索（无后端 + CORS 限制，见上文「搜索范围」节）
- 阅读数据存在浏览器本地，换浏览器 / 清缓存会丢失，重要数据请用「备份导出」留存
- 微信内置浏览器内核较旧，若打开后白屏，请点右上角「…」→ 在浏览器打开
