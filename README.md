## ✨ 功能特性

### 阅读体验
- 📖 **翻页模式** — 支持滚动/翻页两种阅读模式，翻页带滑动、淡入动画和翻书阴影
- 📱 **手机左右点击翻页** — 左三分之一翻上页，右三分之一翻下页，中间点击唤出顶栏
- 🔊 **TTS 语音朗读** — 内置 Web Speech API 朗读引擎，支持播放/暂停/上句/下句
- 📝 **词典划词 & 翻译** — 选中文字即可查询释义和翻译
- 🎨 **5套主题** — 日间、夜间、护眼绿、森林、海洋，支持跟随系统深色模式
- 🌡️ **护眼色温** — 可调节暖色滤镜减轻夜间阅读疲劳

### 书库管理
- 📚 **内置4本公版书** — 爱丽丝漫游奇境、爱丽丝镜中奇遇、德古拉、白鲸记（共147万字）
- 📥 **多格式导入** — 支持 TXT / EPUB / HTML / Markdown / PDF 格式
- 🌐 **网址抓取** — 输入 URL 自动提取网页正文
- 🎨 **封面墙视图** — 精美书架封面展示 + 列表视图切换
- 📊 **阅读统计** — 累计阅读时长、连续阅读打卡日历

### 阅读辅助
- 🔍 **全文搜索** — 高亮命中内容并自动定位
- 🔖 **书签** — 快速标记和跳转重要位置
- 📒 **笔记** — 选中文字添加笔记，支持管理
- 💾 **进度自动保存** — 所有进度、设置、书签、笔记自动存到本地
- 📤 **备份导出** — 一键导出/恢复全部数据

### 技术特点
- 零依赖、零安装、纯离线
- 响应式设计：PC / 平板 / 手机全适配
- 键盘快捷键支持
- 数据存储在浏览器 localStorage，不上传服务器

## 🚀 快速开始

1. 下载 `reader.html`
2. 双击用浏览器打开（推荐 Chrome / Edge / Safari）
3. 开始阅读！

## ⌨️ 快捷键

| 按键 | 功能 |
|---|---|
| `←` / `→` | 上一页 / 下一页 |
| `PageUp` / `PageDown` | 上一页 / 下一页 |
| `Esc` | 关闭面板 / 退出阅读 |
| 手机左/右屏幕点击 | 翻页 |
| 手机中间屏幕点击 | 显示/隐藏顶栏 |

## 📱 支持的设备

- Windows / macOS / Linux 桌面浏览器
- iPhone / iPad (Safari, Chrome)
- Android 手机/平板
- 支持拖拽上传和文件选择器导入
